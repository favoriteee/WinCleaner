# WinCleaner - Lightweight Windows Optimizer & Junk Cleaner

A simple, fast, and powerful `.bat` script to deep clean system junk, clear temporary caches, and optimize your Windows PC performance.

## 🚀 Key Features
* **User Temp Cleaner:** Wipes out application and browser leftovers from the `%TEMP%` directory.
* **System Temp Cleaner:** Safely cleans the main `C:\Windows\Temp` folder.
* **Windows Update Cache Purge:** Temporarily stops the update service to delete gigabytes of old downloaded installation files, then restarts it.
* **DNS Cache Flush:** Resets your network DNS cache to fix loading glitches and optimize connection speed.
* **Auto-UAC:** Automatically requests Administrator privileges to ensure all system files are cleaned successfully.

## 🛠 How to use it?
1. Download the `WinCleaner.bat` file (or pack it into a ZIP archive).
2. Right-click the file and select **Run as Administrator** (or just double-click it, and it will ask for rights automatically).
3. Press any key in the console to start the optimization.
4. Once completed, your PC will be free of unnecessary system clutter!
